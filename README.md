# Vignan University - B.Tech Academic Hub, Study Timer & MERN Lab

A comprehensive, responsive single-page web dashboard built for students at **Vignan's Foundation for Science, Technology & Research (VFSTR), Vadlamudi**. This platform serves as a central hub for academic task tracking, Pomodoro study timing with ambient focus sound generation, academic schedule and holiday planning, GPA and attendance estimation, GATE/Placement preparation, and an interactive **MERN Stack & React Lab**.

---

## 🌟 Key Features

* **Student Authentication & Profile System**: Login modal requiring valid Registration Number matching credentials with quick demo access, personal profile displays, and department/semester selectors.
* **Academic Dashboard & Task Tracker**: Semester completion progress bar, study streak counter, daily class schedules, and a custom task manager for homework, assignments, and exam dates.
* **Productivity Suite & Study Timer**:
  * Customizable Pomodoro timer (25m), Short Break (5m), Long Break (15m), and Stopwatch mode.
  * Real-time circular progress indicator with visual feedback.
  * Web Audio API synthesized ambient noise generator (**Rain**, **Waves**, and **White Noise**).
  * Session completion tracker with subject tagging and study session logging.
* **VFSTR Academic Calendar & Holidays**: Timeline overview of semester events, exams, labs, and official university holiday listings with filtering by event categories.
* **Digital Engineering Library**: Filterable repository of core engineering textbooks across CSE, ECE, Mathematics, and modern full-stack web technologies.
* **GPA & Attendance Calculators**:
  * **SGPA/CGPA Estimator**: Interactive calculator using VFSTR grading system grade point mappings ($S, A, B, C, D, F$).
  * **75% Attendance Margin Analyzer**: Calculates current attendance percentage and safe "bunk/absence" margin to stay above academic threshold limits.
* **MERN Stack & React Engineering Lab**:
  * **Architecture Visualizer**: Interactive diagram showing real-time interaction between MongoDB, Express.js, React.js, and Node.js.
  * **REST API Simulator**: Functional HTTP request client (`GET`, `POST`, `PUT`, `DELETE`) simulating live Express backend responses and MongoDB document storage.
  * **React Sandbox**: Interactive demonstrations of core React concepts like `useState` hooks and controlled form data binding.
  * **Full-Stack Code Generator**: Ready-to-use production boilerplates for `server.js`, Mongoose schemas, and React fetch hooks.
* **AI Study Assistant**: Interactive AI tutor interface offering explanations on Data Structures, MERN stack routes, and core engineering concepts.
* **Dark / Light Theme Support**: Fully customizable UI using Tailwind CSS theme extension.
